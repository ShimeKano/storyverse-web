# Frontend

React + Vite client cho StoryVerse.

## Pages

- `/upload` - Đăng tải nội dung story/chapter
- `/play` - Gameplay
- `/leaderboard` - Bảng xếp hạng
- `/player` - Hồ sơ người chơi
- `/admin` - Admin/Manager only

## Run

```bash
cp .env.example .env
npm ci
npm run dev
```

## Build

```bash
npm run build
```
