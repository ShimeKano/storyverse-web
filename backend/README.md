# Backend

Node.js + Express API cho StoryVerse.

## Features

- Auth (register/login/JWT)
- Story upload/edit/submit/review
- Gameplay engine (node/choice/ending)
- Profile/hearts/progress/inventory
- Leaderboard
- Admin/Manager role enforcement
- Azure-ready config + local fallback

## Run

```bash
cp .env.example .env
npm ci
npm run dev
```

## Test

```bash
npm test
```
