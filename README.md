# StoryVerse

StoryVerse là nền tảng web game gồm:

- Horror Story (nhiều kết thúc)
- RPG Story
- User Profile
- Heart System
- Ranking System
- Story Creator
- Admin Dashboard

## Tech Stack

Frontend:
- React
- Vite

Backend:
- NodeJS
- Express

Database:
- Azure SQL

Cloud:
- Azure Static Web Apps
- Azure App Service

CI/CD:
- GitHub Actions
