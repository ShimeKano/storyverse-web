# StoryVerse

StoryVerse là nền tảng web game cộng đồng cho phép người chơi:

- Chơi truyện kinh dị nhiều kết thúc
- Chơi RPG Story
- Tạo và chia sẻ truyện
- Thu thập ending
- Tích lũy EXP
- Leo bảng xếp hạng

## Features

### Player
- Register/Login
- Profile
- Heart System
- Rankings
- Story Progress

### Creator
- Create Story
- Edit Story
- Submit for Review

### Admin
- Manage Users
- Review Stories
- Manage Rankings

## Tech Stack

Frontend:

Backend:
